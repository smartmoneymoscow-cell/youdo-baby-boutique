
# План доработки премиум-магазина

Работы много — разбиваю по блокам. Всё делаю фронтенд-only (без бэкенда), логин админа/клиента — фейковый через localStorage, как ты и просил.

## 1. Главный экран (Hero)
- Заменить сгенерированную ИИ семью на реальное стоковое фото семьи (родители + ребёнок). Возьму бесплатное фото с Unsplash/Pexels (лицензия permissive), сохраню в `src/assets/` через `lovable-assets`.
- Устранить «прыгание» высоты слайдера: зафиксировать высоту hero-контейнера через `min-h`/`aspect-ratio`, картинка справа — фиксированный квадрат, текстовый блок — с `min-h` по самому длинному слайду. Все фото прогружаю заранее (`<link rel="preload">` или `new Image()`).
- Проверить премиальность: типографика, отступы, тени.

## 2. Каталог
- Отдельный маршрут `/catalog` — полноценная страница под 5000+ SKU:
  - Sticky-сайдбар с фильтрами (категория, возраст, бренд, цена, цвет, размер, только в наличии, только со скидкой).
  - Поиск с debounce, чипы активных фильтров, сортировки, пагинация/«показать ещё».
  - Плотная сетка карточек (адаптивно 2/3/4/5 колонок), скелетоны загрузки.
  - Хлебные крошки, счётчик найденных товаров.
- На главной — упрощённая витрина с CTA «Смотреть весь каталог» → `/catalog`.
- Расширю моковую базу товаров (сгенерирую ~120 позиций программно из существующих) чтобы каталог выглядел живым.

## 3. Карточки товара
- Добавить постоянно видимую кнопку «В корзину» на каждой карточке в каталоге (не только на hover). Fly-to-cart анимация остаётся.
- В карточке товара (модалка) кнопка уже есть — оставляю.

## 4. Главная — фикс верстки
- Выровнять высоту контейнера фильтров на главной по сетке карточек (grid, `items-stretch`).
- Отцентровать заголовок «Популярные» внутри блока.
- Переделать строку поиска: премиальный стиль, крупный инпут с иконкой.
- Добавить CTA-кнопку «Каталог» → `/catalog` рядом с поиском.

## 5. Хедер и футер
- Убрать пункты «Опт» и «Бренды» из навигации в `Header.tsx` и `Footer.tsx`.
- В хедере: кнопка «Войти» открывает модалку входа (единая для админа и клиента, роль определяется логином/паролем).

## 6. Логотип
- Нарисовать SVG-логотип: плюшевый мишка + вордмарк «Заказ с YouDo». Стиль — премиум, монохром (navy) + акцент (cream). Использую inline SVG-компонент `Logo.tsx`, чтобы можно было красить через `currentColor`.

## 7. Авторизация (фейковая)
- `src/lib/auth.ts` (Zustand + persist): роли `admin` / `customer`, единые креды `Админ / 123`.
- Модалка входа `LoginDialog.tsx` из хедера.
- После входа в хедере: аватар + меню (Профиль / Админка / Выйти).

## 8. Страница администратора `/admin`
Гард по роли `admin`, иначе редирект на `/`.
Разделы (табы):
- **Статистика**: карточки (заказы, выручка, средний чек, конверсия) + простые графики (recharts) — данные моковые из localStorage.
- **Товары**: таблица с поиском/фильтром, редактирование (модалка), добавление, удаление.
- **Импорт/Экспорт**: кнопки «Экспорт CSV» (реально скачивает), «Импорт CSV» (парсит и добавляет в стор). Показываю превью.
- **Заказы**: список моковых заказов со статусами.

## 9. Страница клиента `/account`
Гард по роли `customer` или `admin`.
- Профиль (имя, email, телефон — редактируемые, хранятся локально).
- История заказов (моковые данные + реальные оформленные в этой сессии).
- Бонусы: баланс, история начислений/списаний, прогресс-бар до следующего уровня («Baby → Premium → Gold»).

## 10. Оформление заказа
- В `CartDrawer` кнопка «Оформить» создаёт заказ (сохраняется в стор `useOrders`), начисляет бонусы (5% от суммы), очищает корзину, показывает toast, ведёт на `/account`.

## 11. Премиальные анимации
- Motion for React: плавные переходы страниц (`AnimatePresence` на роутах), stagger-появление карточек, parallax на hero-декоре, hover-микровзаимодействия на кнопках, анимация чисел (бонусы, счётчики).
- Дополнить существующие `fly-to-cart` и `cart-pop`, добавить `shimmer` для скелетонов каталога.

## 12. Адаптив и верстка
- Пройти по всем страницам (главная, каталог, админка, клиент, модалки) на web / tablet / mobile через Playwright, снять скриншоты, поправить: переносы текстов, `min-w-0`, `truncate`, отступы, наложения, центровку.

## Технические детали
- Роуты (файлы под `src/routes/`):
  - `catalog.tsx`, `admin.tsx`, `account.tsx`, `login.tsx` (или модалка вместо страницы).
- Новые компоненты: `Logo.tsx`, `LoginDialog.tsx`, `CatalogFilters.tsx`, `AdminStats.tsx`, `AdminProducts.tsx`, `AdminOrders.tsx`, `AccountOrders.tsx`, `AccountBonuses.tsx`, `UserMenu.tsx`.
- Новые сторы: `auth.ts`, `orders.ts`, расширение `products` для админского CRUD (моки в localStorage).
- Пакеты: `recharts` (графики), `papaparse` (CSV). Установлю через `bun add`.

## Что НЕ делаю
- Реальный бэкенд/БД/платежи/почту — только фронтенд-моки в localStorage.
- Реальную регистрацию — только фейковый вход по указанным кредам.

Готов приступить, подтверди план — и начну реализовывать по порядку (это будет несколько итераций правок).
